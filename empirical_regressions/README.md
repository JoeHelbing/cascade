# Empirical Regressions

R workflow and outputs for the empirical protest-data section of the project.

## Contents

| Path | Purpose |
|---|---|
| `building_protest_dataset.R` | Builds the protest dataset used by the regressions. |
| `creating_final_dataset.R` | Produces the final analysis dataset. |
| `protest_analysis.R` | Runs the regression analysis and writes tables/figures. |
| `prot_country_year_pop_mil.csv` | Committed input/intermediate data used by the scripts. |
| `tables/` | Generated regression tables and figures currently kept for paper inspection. |

This directory was moved from `R_regressions/` so the root layout distinguishes empirical R analysis from the simulation/verification pipeline.
